# ワンダリング・ご主人（試作版）

ペットになって、自称「伝説の勇者」なご主人（AI・とても無能）を魔王の玉座まで送り届ける、ローカル協力プレイ用のローグライクです。

## 遊び方

`index.html` をブラウザ（Chrome / Edge / Firefox）で開くだけで遊べます。インストールは不要です。

1. 各プレイヤーが自分のアクションボタンを押して参加します（1〜4人）。左右キーで別のペットに乗り換えられます。
2. `P` キー（またはゲームパッドの START、または「冒険に出る」ボタン）で開始します。
3. ご主人は勝手に歩き回ります。地下5階の魔王を倒し、ご主人を玉座に座らせれば勝ちです。ご主人のHPが0になると全員の負けです。

| プレイヤー | 移動 | アクション |
|---|---|---|
| P1 | W A S D | Space |
| P2 | 矢印キー | Enter |
| P3 | I J K L | U |
| P4 | T F G H（テンキー 8/4/5/6 でも可） | R（テンキー 0 でも可） |
| ゲームパッド | 左スティック / 十字キー | A |
| スマホ | 画面下のパッド（P1として参加） | A |

## ペット

| ペット | アクション | 特徴 |
|---|---|---|
| 🐕 ポチ | 吠える | 周りの敵を5秒間引きつけ、ご主人を自分の方へ呼び寄せる |
| 🐈 タマ | 罠解除 / 爪とぎ | 近くの罠を発見し、キノコと薬を鑑定する。眠気が100%になると5秒昼寝する（爪とぎで眠気を下げられる） |
| 🦉 ホー助 | 頭に止まる / 飛び立つ | ご主人の頭に止まると階全体が見える。罠を踏まない |
| 🟢 プル | 食べる | ご主人の装備を食べて別の装備に変える。床のアイテムを食べて、ご主人に拾わせないこともできる |

全ペット共通：
- 敵にぶつかると攻撃します。
- ご主人にぶつかると1マス押します。進路に立つと通せんぼになります。
- 気絶しても8秒で起き上がります。

## ご主人

ランごとに名前と性格がランダムで決まります。

- **臆病**：敵が近いと逃げ出す
- **食いしん坊**：キノコと肉に目がない
- **収集癖**：宝箱と装備を見ると突進する
- **好奇心旺盛**：寄り道ばかりで、見つかった罠を踏みたがる

## 謎アイテム

| アイテム | 効果 |
|---|---|
| 🍄 あやしいキノコ | 巨大化（攻撃力アップ、歩くと天井が崩れる）/ 回復 / 毒＋混乱 / 睡眠 |
| 🧪 謎の薬 | 回復 / 俊足 / 混乱 |
| 👑 逆さまの王冠 | ご主人がペットに命令を出す。命令と**逆**に動くとご機嫌になって回復する |
| 🗡️ しゃべる剣 | 強い。装備中にご主人へぶつかると、剣と交渉して5秒間ご主人を直接操作できる |
| 🍳 フライパン / 🧸 ぬいぐるみ | そこそこ強い / 攻撃できないが少しずつ回復する |
| 💍 呪いの指輪 | 15秒間透明になる。敵にも見えないが、みんなにも見えにくい |
| 📯 謎の角笛 | 吹くと階じゅうの敵が目を覚まして集まってくる |
| 📦 宝箱 | ご主人は必ず開ける。3割はミミック |
| 🍖 骨つき肉 | ペットが先に踏めばペットが回復する |
