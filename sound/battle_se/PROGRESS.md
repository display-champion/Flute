# バトルの攻撃系 SE 作業経過

ユーザー指示：「バトルで使用する攻撃系のSEを作成してください」

## 方針

- 何を作るかは `バトル一覧.xlsx`（通常攻撃・スキル攻撃・モンスタースキル・ダンジョン雑魚・共通ルール）から拾い、前回の魔法陣（8属性の玉・ビーム）の音も加える
- 録音素材は使わず、Python（numpy / scipy）で一から合成する。44.1kHz・16bit・モノラルの WAV
- 音量は種類ごとにそろえる（振り音は小さめ、命中・爆発は大きめ）。ループ用はつなぎ目が切れないように作る
- 確認用 HTML（再生ボタン・波形つき）と、Unity 用の再生スクリプト（`BattleSE.cs`：名前で鳴らす／AnimationEvent の OnMotionEvent から鳴らす）を付ける
- 作業ファイル：`tools/make_se.py`（全部の音の作り方）→ `out/`。納品は zip、git からは作業ファイルを消してこのファイルだけ残す

## 作業ログ

- 開始：一覧（87 音）を決定
- `tools/dsp.py`（雑音・時間で変わるフィルター・発振器・残響・音量合わせ）と `tools/make_se.py`（87 音の作り方）で合成
- 耳で聞けないため、波形と周波数の図・「プツッ」の検出・ループのつなぎ目・ピーク／DC を数値で確認して直した
  - 部品のおしりが途中で切れて「プツッ」となる → 重ねるときに 6ms で消す
  - 30Hz 未満の成分で波形がふらつく（ループが特に）→ 雑音から 30Hz 未満を除く
  - 鞭・針などの鋭い音が頭打ちで 8dB もつぶれる → 丸める量を 3dB までにして、超えるぶんは全体を下げる
  - 息を吸う・雷の玉・風の着弾のおしりが急に切れる → 長さと消え方を調整
- 確認用 `preview.html`（音を埋め込み。再生・波形・絞り込み・ループ再生）、Unity 用 `BattleSE.cs`（名前で鳴らす・ループ・位置・揺らぎ・同時数の制限）と `SEEventMap.cs`（OnMotionEvent → SE、魔法陣の既定つき）。Unity での動作は未確認
- 納品：`HELLEDEN_BattleSE.zip`（`battle_se/` ができる。Resources フォルダはそのまま置く）
- 作業ファイルは git から削除。全部そろった状態はコミット `e07e4c4` で取り出せる（例：`git checkout e07e4c4 -- sound/battle_se`）
