# バトルの攻撃系 SE 作業経過

ユーザー指示：「バトルで使用する攻撃系のSEを作成してください」

## 方針

- 何を作るかは `バトル一覧.xlsx`（通常攻撃・スキル攻撃・モンスタースキル・ダンジョン雑魚・共通ルール）から拾い、前回の魔法陣（8属性の玉・ビーム）の音も加える
- 録音素材は使わず、Python（numpy / scipy）で一から合成する。44.1kHz・16bit・モノラルの WAV
- 音量は種類ごとにそろえる（振り音は小さめ、命中・爆発は大きめ）。ループ用はつなぎ目が切れないように作る
- 確認用 HTML（再生ボタン・波形つき）と、Unity 用の再生スクリプト（`BattleSE.cs`：名前で鳴らす／AnimationEvent の OnMotionEvent から鳴らす）を付ける
- 作業ファイル：`tools/make_se.py`（全部の音の作り方）→ `out/`。納品は zip、git からは作業ファイルを消してこのファイルだけ残す

## 作業ログ

- 開始：一覧（約 87 音）を決定
- 第2版（ユーザーの試聴を受けて）：
  - 指示「ジャスト回避開始はもっとブゥン系で／時間停止が解けるときはキンキン系ではなくフゥゥン系で／ほかキンキン系は全てやめて（氷と雷系のみ許可）／鎖が『カキン』に聞こえる、もっと重厚感を全体的に」
  - 金属の響き・鈴・きらめきを氷と雷以外すべて削除：剣の刃鳴り、斬撃命中の響き、攻撃予告（キィン→低い「ヴォン」）、鋏（→「ガシュッ」）、鎖（→ 鈍い「ゴロゴロ→ドガッ」）、光の矢・光の玉と着弾・魔法陣の出現・光の柱（澄んだ和音→低い和音）、眠り粉・胞子・合体攻撃・撃破・光のブレスのきらめき
  - ジャスト回避：太いうなりが沈んでいく「ブゥン」＋吸い込み＋低い「ドン」（時計の音は削除）。時間停止の解除：柔らかい風と低いうなりの「フゥゥン」
  - 全体の重厚感：風切りを 0.72 倍の高さにして胴を厚く、「ドン」の余韻を 1.3 倍、仕上げに低音 +5dB（160Hz 以下）・高音 -5dB（4.5kHz 以上、氷と雷は高音を残す）
