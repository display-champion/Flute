# 操作系・マップ系 SE 作業経過

ユーザー指示：「歩き、走り、ジャンプ等操作系の音／イベント時のスイッチオン、壁が降りる音、扉を開く音など／マップ系に関わる音で必要そうなものを探して追加してください」

## 方針

- バトル一覧.xlsx（フィナの移動・アイテム、空鯨戦のバリスタと銛、ダンジョンのギミック：宝箱・樽・箱・ランタン・光の道・錬成の橋・水路・溶岩・沼・風車・休憩所 など）から拾う
- 攻撃 SE 第2版の指示を引き継ぐ：キンキン系（金属の響き・鈴・きらめき）は使わず、全体を重厚に
- 足音は地面の種類ごとに 4 通り（連続で同じ音にならないように）。走りは同じ足音を強めに鳴らす
- 作り方は攻撃 SE と同じ（Python で合成、44.1kHz・16bit・モノラル WAV、確認用 HTML、Unity 用スクリプト）
  - Unity：`FieldSE.cs`（名前で鳴らす。BattleSE と同じ使い方で、BattleSE が無くても動く）、`FootstepSE.cs`（足元の地面を調べて足音・ジャンプ・着地を鳴らす）
- 納品は zip、git からは作業ファイルを消してこのファイルだけ残す

## 作業ログ

- 開始：一覧を決定（足音 7 種類 × 4、操作、仕掛け、バリスタ、環境ループ）
- 合成（`tools/make_se.py`）。攻撃 SE の道具（`dsp.py`）に、ゆっくり揺れる乱数（`slow_noise`）を追加（フィルターは 20Hz 未満を作れず、風や水のゆらぎが速すぎたため）
- 数値の確認で直したもの：木のきしみ（扉・風車・昇降機）が引っかかりを「オン／オフ」で作っていて「プツプツ」になる → なめらかな引っかかりに
- 確認：全部 44.1kHz・16bit・モノラル、ピーク -1dB 以下、「プツッ」なし（火・溶岩のパチパチは意図どおり）、ループのつなぎ目は普段の波と同じ程度、4kHz 以上の成分は全体の 6% 未満（キンキン系なし）
- Unity 用：`FieldSE.cs`（BattleSE と同じ使い方＋ `PlayStep`：4 通りから前回と違う足音）、`FootstepSE.cs`（歩いた距離で足音・ジャンプ・着地を自動。足元は FootstepSurface → テレインレイヤー名 → Physic Material 名 → マテリアル名 → 名前・タグ で判定）、`FootstepSurface.cs`。Unity での動作は未確認
- 納品：`HELLEDEN_FieldSE.zip`（`field_se/` ができる）。作業ファイルは git から削除。全部そろった状態はコミット `197150d` で取り出せる（例：`git checkout 197150d -- sound/field_se`）
